# Applications tracker

The single source of truth for what Desiree has applied to. **Only Desiree edits this
file.** The scheduled agent reads it (for the 14-day company block and the Gmail scan)
and proposes updates in the pulse, but never writes here directly.

## Stage values

`Sent`, `Auto-rejected`, `Rejected`, `Recruiter screen`, `Hiring manager`,
`Tech/panel`, `Onsite`, `Offer`, `Withdrew`, `Ghosted`.

- Mark `Ghosted` when a role has been `Sent` for over 30 days with no reply.
- `Auto-rejected` = automated rejection within a day or two; `Rejected` = a human no
  after some engagement.
